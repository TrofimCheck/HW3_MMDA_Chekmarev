# Подборка вин: демо-приложение на Streamlit

## Запуск

Версия Python: 3.13.

```bash
cd wine_app
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение откроется в браузере по адресу http://localhost:8501.

## Кэширование

**Почему для модели `st.cache_resource`, а для таблиц `st.cache_data`.** `st.cache_resource` хранит один объект на весь сервер и при каждом вызове отдаёт этот же объект, без копирования. Это подходит для «ресурсов», которые не нужно менять и которые дорого создавать заново: модели, подключения к базе. `st.cache_data` предназначен для данных (DataFrame, массивы): результат функции сериализуется, и при каждом вызове возвращается его новая копия. Поэтому если код случайно изменит таблицу, кэш не испортится, и разные пользователи не будут мешать друг другу. Для модели копирование не нужно: она в приложении не изменяется, а сериализация и копирование при каждом обращении только тратили бы время и память.

**Что будет без декоратора.** Streamlit перезапускает `app.py` сверху вниз при каждом действии пользователя. Если вызывать `joblib.load` без кэширования, модель будет заново читаться с диска и десериализоваться при каждом движении слайдера, каждом вводе значения и т.д. Приложение станет медленнее, будет лишняя нагрузка на диск, а при нескольких пользователях в памяти может оказаться сразу много копий модели.
